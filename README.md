# Python Tip Calculator

A simple command-line tip calculator built with Python.

## Features

- Enter the total bill amount.
- Choose a tip percentage (10%, 12%, or 15%).
- Split the bill between multiple people.
- Calculate the amount each person should pay.
- Round the final amount to two decimal places.

## Technologies Used

- Python 3

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/sinabahrinie/python-tip-calculator.git
   ```

2. Navigate to the project folder.

3. Run the Python file:
   ```bash
   python task.py
   ```
